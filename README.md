# TP POO - Gestion de matériel informatique
## Objectif
Ce projet permet de manipuler les notions de programmation orientée objet en C# :
- classes
- héritage
- classe abstraite
- polymorphisme
- collection
- règles de gestion
- tests unitaires avec MSTest
## Fonctionnalités
- Ajouter un matériel
- Rechercher un matériel
- Emprunter un matériel
- Retourner un matériel
- Afficher les matériels disponibles
- Afficher tous les matériels
- Calculer la durée maximale totale d’emprunt
- Recherche par état
- Compter les matériels disponibles

## Tests
Les tests unitaires sont placés dans le projet :
TpGestionMateriel.Tests
Pour lancer les tests :
dotnet test
## Branche utilisée
dev-poo-tests
